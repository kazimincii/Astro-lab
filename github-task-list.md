GitHub Pro Görev Listesi (CI/CD, Test ve DevOps)

CI/CD Pipeline Kurulumu: Proje için Sürekli Entegrasyon/Sürekli Dağıtım (CI/CD) süreçlerinin yapılandırılması. Örneğin, GitHub Actions kullanarak her push sonrasında otomatik olarak uygulamayı derleyen, birim testlerini çalıştıran ve sonuçları raporlayan bir iş akışı oluşturulması. CI aşamasında linting ve tip kontrolü (ESLint, TypeScript) de entegre edilerek kod kalitesinin güvenceye alınması.

Birim ve Entegrasyon Testlerinin Yazılması: Hem backend API uç noktaları hem de mobil uygulama için eksik kalan birim testlerinin tamamlanması ve kritik akışlar için entegrasyon testlerinin yazılması. Örneğin, profil oluşturma limitlerini, premium aksiyon günlük limitlerini, ve çeşitli modüllerin (örn. Bioritim hesaplaması, Chakra analizleri) doğru çalıştığını doğrulayan testler eklenecek. Mobil tarafta ekran bileşenleri için React Native Testing Library kullanarak component ve screen testleri yazılacak, böylece halihazırda var olan testler genişletilecek.

Uçtan Uca (E2E) Test Senaryoları: Kullanıcının uygulama içindeki temel yolculuğunu baştan sona doğrulayacak end-to-end test senaryolarının oluşturulması. Örneğin, yeni bir kullanıcının kayıt olup profil oluşturması, ücretsiz deneme başlatması, bir astroloji okuması alması veya journal girdisi eklemesi gibi senaryoların otomatik testlerle simüle edilmesi. Mobil uygulama için Detox veya benzeri bir E2E test aracının entegre edilerek iOS cihaz/simülatör üzerinde kritik akışların test edilmesi hedeflenecek.

Hata Loglama ve İzleme Altyapısı: Uygulama içerisindeki hataların ve istisnaların takip edilebilmesi için bir hata loglama yapısının kurulması. Örneğin Sentry gibi bir hata izleme hizmetinin entegre edilerek hem frontend (React Native) tarafında oluşan crash'lerin hem de backend API hatalarının merkezi olarak toplanması sağlanacak. Bu yapı sayesinde üretimde karşılaşılabilecek hatalar GitHub Pro entegrasyonu ile izlenip geliştirici ekibe anlık bildirim olarak düşebilir. Ayrıca, uygulama içinde hata yakalama (try-catch) bloklarının önemli yerlerde eklenmesi ve konsola yazılan kritik logların geliştirici modda görünmesi de sağlanacak.

Otomatik Build ve Deploy Script'leri: Uygulamanın test ve dağıtım süreçlerini hızlandırmak için GitHub Actions üzerinde otomatik build ve deploy işlemlerini yürüten betiklerin oluşturulması. Örneğin, main branche birleştirilen kodu otomatik olarak Expo EAS veya benzeri bir sistemle derleyip, test uçuşu (TestFlight) ya da Google Play Internal Test gibi platformlara yükleyen bir aksiyon kurulabilir. Benzer şekilde backend için de otomatik deploy (ör. Heroku, AWS) scripti eklenerek CI/CD tamamlanacak. Bu sayede her yeni özellik eklendiğinde manuel işlem yapmadan sürekli entegrasyon ve dağıtım gerçekleşecek.
