# iOS Widgets for Astrology Super-App

This directory contains the iOS Widget Extension for the Astrology Super-App.

## Widget Types

1. **Small Widget** - Moon Phase
2. **Medium Widget** - Star Message of the Day  
3. **Large Widget** - Today's Astro Summary

## Setup

See AstroWidget.swift for implementation details.

App Groups required: `group.com.astrolab.widgets`

## Files

- `AstroWidget.swift` - Main widget implementation
- `Info.plist` - Widget configuration
- `README.md` - This file
