# Astro-lab

## 🚀 Hızlı Başlangıç

### Gereksinimler
- Node.js 18+
- npm veya yarn

### Kurulum

1. **Projeyi klonla:**
```bash
git clone https://github.com/kazimincii/Astro-lab.git
cd Astro-lab
```

2. **Bağımlılıkları yükle:**

#### Mobile (React Native)
```powershell
npm install --prefix astrology-app/mobile
```

#### Backend (NestJS)
```powershell
npm install --prefix astrology-app/backend
```

3. **Projeyi çalıştır:**

#### Mobile Development
```powershell
cd astrology-app/mobile
npm start
```

#### Backend Development
```powershell
cd astrology-app/backend
npm run start:dev
```

## 🎨 Özellikler

- 🔮 **Tarot Okuma** - Günlük tarot yorumları
- ♈ **Astroloji** - Burç horoskopları ve açıklamaları
- 🔢 **Numeroloji** - Sayı analiziyle kişisel rehberlik
- 🧘 **Çakra** - Çakra dengesi ve meditasyon rehberi
- ☕ **Kahve Falı** - Statik görüntülerle eğlenceli falcılık
- 📅 **Astrolojik Takvim** - Özel günler ve etkinlikler
- 💑 **Uyumluluk Analizi** - İki kişi arasında enerji uyumluluğu
- 📱 **iOS Widget'ları** - Ev ekranında hızlı bilgiler
- ⌚ **Apple Watch** - Çekirdek özelliklere erişim
- 🌙 **Biyoritim** - Bedensel, duygusal ve entellektüel döngüler
- 📔 **Kişisel Günlük** - Düşünceler ve tecrübeler kaydı

## 🛠️ Teknoloji Stack

### Frontend
- React Native with Expo

- Tailwind CSS
- React Navigation

### Backend
